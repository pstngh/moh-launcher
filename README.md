# moh-launcher

macOS launcher for OpenMoHAA. Connect starts `openmohaa.app`. Play starts `mohbots.app`.

The built app for Apple silicon (macOS 15 or later) is on the [releases](https://github.com/pstngh/moh-launcher/releases) page. Unzip into the game folder, next to `openmohaa.app`, then run `install.command` once.

`./bundle.sh` builds `launcher.app` in the current folder.
